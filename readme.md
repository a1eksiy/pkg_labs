# Лабораторная работа 3 — вариант 5

## Реализованные методы
Вариант 5 соответствует пересечению строки «Построение и эквализация гистограммы изображения + линейное контрастирование» и столбца «Реализация нелинейных фильтров, основанных на порядковых статистиках».

### Порядковые (rank) фильтры
Они рассматривают окрестность пикселя, сортируют значения и выбирают элемент с заданным рангом. В отличие от линейной свёртки, результат не является взвешенной суммой соседей.

- **Медианный фильтр** выбирает центральное значение отсортированной окрестности. Хорошо удаляет импульсный шум («соль и перец»), обычно сохраняя края лучше усреднения.
- **Минимум** выбирает самое тёмное значение. Подавляет яркие выбросы, но расширяет тёмные области.
- **Максимум** выбирает самое светлое значение. Подавляет тёмные выбросы, но расширяет светлые области.
- **Процентильный фильтр** выбирает значение заданного процентиля. 0% соответствует минимуму, 50% — медиане, 100% — максимуму. Промежуточные значения позволяют смещать результат в сторону более тёмных или светлых значений.

Для каждого пикселя формируется квадратная окрестность радиуса r (размер (2r+1)×(2r+1)). На границах используется отражение пикселей. Фильтры применяются отдельно к RGB-каналам.

### Линейное контрастирование
Для каждого канала значения растягиваются от наблюдаемого диапазона [min,max] до [0,255]:
`out = (in-min)*255/(max-min)`.
Это увеличивает использование диапазона яркостей, когда изображение занимает узкую часть шкалы. Если канал постоянный, он сохраняется без изменений.

### Эквализация гистограммы
Гистограмма подсчитывает количество пикселей каждого уровня 0–255. По накопленной гистограмме строится LUT (таблица преобразования), которая распределяет интенсивности по более широкому диапазону.

- **RGB-эквализация:** каждый канал R, G и B эквализуется отдельно. Может повышать контраст, но способна изменять цветовой баланс.
- **Эквализация яркости HSV:** RGB переводится в HSV, эквализуется компонент V, затем изображение возвращается в RGB. Hue и Saturation сохраняются, поэтому этот способ обычно меньше меняет оттенки.

Эквализация может усиливать шум и не всегда улучшает изображение; её результат зависит от исходной гистограммы.

## Интерфейс
Открытие изображения, выбор метода, настройка радиуса и процентиля, просмотр исходного изображения и результата, сброс и сохранение результата. Под изображениями отображаются статистики гистограмм RGB (минимум, максимум и среднее значение каждого канала).

## Структура
- `main.py` — запуск приложения.
- `ui/main_window.py` — Qt-интерфейс, загрузка/сохранение, вызов методов.
- `processing/filters.py` — rank-фильтры, контрастирование, преобразования RGB/HSV и эквализация.
- `processing/histogram.py` — вычисление гистограмм каналов.

## Запуск
Требуется Python 3.10+:
```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
python main.py
```

## Сборка EXE
Из корня проекта:
```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name Variant5ImageProcessing main.py
```
Исполняемый файл появится в `dist/Variant5ImageProcessing.exe`. Для сборки на Windows следует выполнять команды в Windows. Если нужна сборка без консоли и единый exe, параметры `--windowed --onefile` это обеспечивают.
