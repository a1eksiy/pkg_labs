# Лабораторная работа № 2 — чтение информации из графических файлов

Настольное приложение на Python 3.12 и PySide6. Метаданные извлекаются собственными парсерами без Pillow, OpenCV, ImageMagick и других библиотек чтения изображений.

## Возможности

- Форматы: BMP, PNG, JPEG, GIF, TIFF и PCX.
- Выбор отдельных файлов или папки, рекурсивный обход.
- Ограниченный пул потоков, чтение заголовков и структурных блоков без декодирования изображения целиком.
- Таблица с сортировкой, поиском, фильтром статуса, прогрессом и отменой.
- Экспорт CSV в UTF-8 с BOM для совместимости с Excel.
- Ошибки чтения, неподдерживаемые форматы и повреждённые файлы отображаются отдельно.

## Запуск из исходников

Требуется Python 3.12.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

## Сборка EXE на Windows

Собирать приложение нужно в Windows-среде той же разрядности, что и целевая система.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
pyinstaller --noconfirm --clean --windowed --onefile --name ImageMetadataReader main.py
```

Готовый файл будет в `dist\ImageMetadataReader.exe`. На целевом компьютере Python не требуется; системные библиотеки Windows должны соответствовать требованиям PySide6.

## Ограничения

Проверяется структура метаданных, а не полная декодируемость всех пикселей. JPEG проверяется на наличие EOI, но поиск маркера в скан-данных не доказывает целостность всего потока. PNG проверяет CRC прочитанных чанков и IEND, но не распаковывает весь IDAT. TIFF читает IFD и значения тегов; содержимое полос/тайлов не декодируется. Для очень больших файлов обработка TIFF-метаданных ограничена защитными лимитами. DPI выводится только при наличии соответствующих тегов. Отсутствующее значение оставляется пустым.

## Поддержка форматов

- BMP: заголовок файла, DIB, палитра, bpp, смещение пикселей и распространённые коды сжатия.
- PNG: сигнатура, IHDR, размеры, цветовой тип, глубина, методы и CRC чанков, IEND.
- JPEG: сегменты, SOF, JFIF DPI, базовые EXIF-теги разрешения, EOI.
- GIF: GIF87a/GIF89a, глобальная и локальная палитра, блоки, количество изображений-дескрипторов, trailer.
- TIFF: II/MM, классический TIFF, цепочка IFD, типы и смещения значений, BitsPerSample, SamplesPerPixel, разрешение и compression.
- PCX: 128-байтовый заголовок, координаты, DPI, bpp, planes, bytes per line и RLE-флаг.

## Статусы

- `Метаданные прочитаны` — основные метаданные извлечены, это не гарантия полной целостности.
- `Файл повреждён` — обнаружено нарушение ожидаемой структуры или неожиданный конец файла.
- `Неподдерживаемый формат` — формат не распознан или не поддерживается.
- `Ошибка чтения` — например, отказ доступа или ошибка файловой системы.
